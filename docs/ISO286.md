# ISO 286 geçme sınıfları — sayısal referans

> `⌀25 H7` üç karakterde `⌀25 +0,021/0` ile aynı bilgiyi taşır. Bu modül gelene
> kadar denetleyiciler bir geçme sınıfını **bilinmeyen** sayıyordu; artık gerçek
> sapmalara çözülüyor ve ters tolerans, hane uyumu, ISO 2768 karşılaştırması,
> tolerans birikimi gibi tüm sayısal kurallar geçmeli ölçülerde de çalışıyor.
>
> Kaynak: [`standards/iso286.py`](../src/catia_diff/standards/iso286.py) —
> aşağıdaki tablolar doğrudan o modülden üretilmiştir.

---

## 1. Model

İki tablo her şeyi belirler:

| Tablo | Ne belirler |
| --- | --- |
| **IT dereceleri** (IT5–IT14) | Tolerans bölgesinin **genişliği** |
| **Temel sapmalar** (harf) | Bölgenin nominal ölçüye göre **konumu** |

`⌀25 H7` → 18–30 aralığı, IT7 = 21 µm, `H` harfi deliklerde EI = 0 →
**+0,021 / 0**.

## 2. Doğruluk: tablolar formülle çapraz denetleniyor

ISO değerleri tablo hâlinde sabitler, ancak standart bu tabloların türetildiği
formülleri de verir:

```
i = 0,45·∛D + 0,001·D          (standart tolerans faktörü, µm)
IT5 = 7i · IT6 = 10i · IT7 = 16i · IT8 = 25i · IT9 = 40i …
g = −2,5·D^0,34 · f = −5,5·D^0,41 · e = −11·D^0,41 · d = −16·D^0,44
m = IT7 − IT6 · n = +5·D^0,34 · k = +0,6·∛D
```

[`tests/test_iso286.py`](../tests/test_iso286.py) **her hücreyi** bu eğriye karşı
doğrular: bir rakam hatası, eğriden sapan bir değer olarak teste takılır. Kabul
bandı `maks(1 µm, %8)` — ISO'nun tercih edilen sayılara yuvarlamasına izin verir,
transkripsiyon hatasına vermez. İlk aralık (0–3 mm) bu denetimin dışındadır:
standart o aralığın değerlerini formülden değil doğrudan verir.

> **Sınır:** Tablolar bu pakette yeniden üretilmiştir ve yukarıdaki iç tutarlılık
> denetiminden geçer; buna rağmen bağlayıcı kaynak satın alınan ISO 286-1
> standardıdır. Kritik bir imalat kararını doğrudan buradaki sayıya dayandırmayın.

### Delikler türetilir, tablolanmaz

Delik sapmaları ayrı bir tablodan değil, standardın kendi kurallarından çıkar —
böylece yanlış girilebilecek sayı miktarı yarıya iner:

| Kural | Kapsam | Formül |
| --- | --- | --- |
| Genel kural | A–H | `EI = −es` (milin aynası) |
| Δ kuralı | K, M, N (≤IT8), P (≤IT7) | `ES = −ei + Δ`, `Δ = IT_n − IT_(n−1)` |
| Simetrik | JS | `±IT/2` |

Doğrulama: `⌀25 K7 = +6/−15`, `M7 = 0/−21`, `N7 = −7/−28`, `P7 = −14/−35` —
dördü de türetilmiş değerlerdir ve testte klasik değerlerle karşılaştırılır.

## 4. Kapsam

| Destekleniyor | Desteklenmiyor |
| --- | --- |
| Miller: `d e f g h js k m n p` | `a b c cd ef fg j r s t u v x y z za zb zc` |
| Delikler: `D E F G H JS K M N P` | yukarıdakilerin büyük harfleri |
| Dereceler: IT5–IT14 | IT01–IT4, IT15–IT18 |
| Ölçüler: 0,5–500 mm | 500 mm üstü |

Kapsam dışı her durum `None` döner — tahmin üretilmez — ve `TOL011` bunu
raporlar, böylece sessizlik "sorun yok" sanılmaz.

## 5. Kurallar

| Kural | Önem | Ne der |
| --- | --- | --- |
| `TOL011` | Minör | Geçme sınıfı sayıya çevrilemedi; **nedeni** söylenir (ölçü / harf / derece) |
| `TOL012` | Bilgi | Geçme sıkı ya da geçiş; hesaplanmış boşluk aralığıyla birlikte |

Ayrıca geçme sınıfları artık şu kurallara **katılır**: `TOL002` (geçersiz aralık),
`TOL008` (genel toleranstan geniş), `TOL009` (genel toleransı tekrar),
`TOL010` (zincirde tolerans birikimi).

### Çift gösterimi

`H7/g6` tek bir parçanın toleransı değil, **montajın** tanımıdır. Bu yüzden tek
ölçü için sapma döndürülmez; bunun yerine boşluk aralığı hesaplanır:

| Çift (⌀25) | Karakter | Boşluk |
| --- | --- | --- |
| `H7/g6` | boşluklu | +7 … +41 µm |
| `H7/h6` | boşluklu | 0 … +34 µm |
| `H7/k6` | geçiş | −15 … +19 µm |
| `H7/p6` | sıkı | −35 … −1 µm |

## 6. Deneme

```bash
python examples/generate_sample_drawing.py examples/sample_fits.dxf --fits
catia-diff audit examples/sample_fits.dxf --lang tr
```

Beklenen: `⌀25 H7/p6` için `TOL012` (sıkı geçme, pres gerekir) ve `⌀40 u6` için
`TOL011` (harf kapsam dışı). Resim başka açıdan tam ölçülendirilmiştir.

```python
from catia_diff.standards.iso286 import parse_fit, deviations, clearance, fit_character

deviations(25.0, parse_fit("H7"))          # (0.021, 0.0)
deviations(25.0, parse_fit("g6"))          # (-0.007, -0.020)
clearance(25.0, parse_fit("H7/p6"))        # (-0.035, -0.001)
fit_character(25.0, parse_fit("H7/k6"))    # 'transition'
deviations(25.0, parse_fit("u6"))          # None — kapsam dışı
```
